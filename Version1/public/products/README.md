# Product photos live here

Files in this folder are public: `public/products/product1.png` is served as
`/products/product1.png`.

The site is currently looking for:

- `product1.png`
- `product2.png`
- `product3.png`

Upload your photos with these exact names to replace the placeholders (square
images work best, e.g. 1200 × 1200 px). To use different names or extensions,
update `src/lib/images.ts`.

Full walkthrough: [`docs/product-images.md`](../../docs/product-images.md)

> The logo is not here — it goes one folder up, at `public/logo.png`.
> A Markdown file in this folder is never displayed on the site; it is only a
> note for whoever uploads the photos.
